# Modelo de Michaelis-Menten para la Cinética Enzimática

Taller de **Modelamiento Matemático** enfocado en el análisis y ajuste del modelo cinético de Michaelis-Menten para describir la velocidad inicial de reacción enzimática ($v_0$) en función de la concentración de sustrato ($[S]$), estimando parámetros cinéticos clave como la velocidad máxima ($V_{\max}$) y la constante de Michaelis ($K_m$).

## Contenido
* Notebook / scripts con el procesamiento de datos, ajuste no lineal o linealizado del modelo, cálculo de parámetros ($V_{\max}$, $K_m$), análisis de residuos y gráficas comparativas.

## Herramientas utilizadas
* **Python 3** y **Jupyter Notebook**
* **NumPy** y **SciPy** (cálculo numérico y ajuste de curvas)
* **Matplotlib** (visualización de datos y ajuste del modelo)
